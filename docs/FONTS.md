# Bundled fonts

All three typefaces are licensed under the SIL Open Font License 1.1 and were
taken from the official Google Fonts repository (github.com/google/fonts, `ofl/`).

| File | Typeface | Use |
|---|---|---|
| `sourceserif4.ttf`, `sourceserif4_italic.ttf` | Source Serif 4 (variable) | headings, readers |
| `poppins_regular/medium/semibold.ttf` | Poppins | body and interface |
| `amiri_regular/bold.ttf` | Amiri | Arabic and Urdu text |

They are bundled rather than downloaded at run time so the first screen already
uses the brand type, on every phone, without Google Play services.
